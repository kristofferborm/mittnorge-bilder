# mittnorge-bilder

Ferdige karusellbilder (1080 × 1350, JPG) for Instagram-kontoene Mitt Norge og My Norway. Buffer henter bildene herfra via raw.githubusercontent.com.

- `mittnorge/<nr>-<tema>/01.jpg …` – én mappe per karusell, slidene i rekkefølge
- `mynorway/<nr>-<tema>/01.jpg …`

Bakgrunnsbilder fra Pexels (fri bruk, også kommersielt).
